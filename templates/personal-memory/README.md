# Personal Memory Template

Copy this folder into a **private** repository for each person.

Suggested private repository structure:
- `AGENTS.md` — how the person's agents should load Shared + private memory.
- `MEMORY.md` — durable personal/project context only.
- `PROJECTS/` — one file per active project.
- `DECISIONS.md` — explicit durable decisions.
- `KNOWN-ISSUES.md` — private project-specific bugs/risks.

The private repository should reference `builder-intelligence-shared` as the common technical feed. Never push personal/private context back to Shared unless it is generalized and sanitized first.
