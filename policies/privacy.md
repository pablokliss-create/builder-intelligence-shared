# Privacy Separation

The Shared repository must contain only generalized technical intelligence.

Never include:
- personal data;
- private project names/details unless intentionally public;
- internal bugs that reveal private implementation details;
- credentials, tokens, keys, account identifiers, or secrets;
- private conversations or model memory;
- customer/company confidential data.

Each user keeps a separate private memory layer. Shared knowledge may feed private projects; private memory must not flow back into Shared unless generalized and sanitized.
