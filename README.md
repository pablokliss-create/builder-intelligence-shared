# Builder Intelligence Shared

Versioned shared technical intelligence for AI agents.

This repository distributes reusable knowledge about tools, Skills, MCPs, engines, frameworks, services, benchmarks, security notes, migration risk, and selection policies.

It intentionally does **not** contain anyone's private project memory, secrets, credentials, personal data, or private bugs.

## How to use
1. Clone or pull this repository before starting/continuing technical work.
2. Read `AGENTS.md`.
3. Read `VERSION.json` and `CHANGELOG.md`.
4. Load only the registry/policies relevant to the current task.
5. Keep your own project memory in a separate private repository or store.
6. Revalidate volatile facts before making expensive architectural decisions.

The shared layer is an intelligence feed, not an automatic installer. Agents must detect what is actually available in their environment and ask for authorization when installation/login/payment is required.
