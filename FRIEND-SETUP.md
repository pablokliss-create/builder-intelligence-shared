# Friend Setup

Goal: use the same up-to-date technical intelligence without sharing anyone else's private memory.

1. Clone `pablokliss-create/builder-intelligence-shared`.
2. Tell your AI agent to read `AGENTS.md` before starting or continuing technical projects.
3. Create a separate **private** memory repository from `templates/personal-memory/`.
4. In that private repo, keep your own project names, decisions, bugs, preferences, and lessons.
5. At the start of work: pull Shared -> load private memory -> inspect the actual project repo.
6. At the end of work: write durable private lessons to your private memory; only generalized/sanitized lessons may be proposed to Shared.

Recommended agent instruction:
`Before technical work, sync builder-intelligence-shared, load my private memory overlay, inspect the target repository, and use current verified evidence instead of stale chat memory.`
