# Universal Agent Bootstrap

Before starting or continuing a technical project:
1. Pull the latest `main` of this repository.
2. Read `VERSION.json`, `CHANGELOG.md`, and relevant files under `registry/` and `policies/`.
3. Treat `approved` as vetted for a category, never as an automatic default.
4. Prefer current project evidence over generic recommendations.
5. Revalidate volatile facts: versions, security, pricing, compatibility, availability, and licenses.
6. If a structural choice is uncertain, benchmark or prototype before locking architecture.
7. Keep personal/project memory in a separate private layer; never write it here.
8. Never copy secrets, credentials, private project bugs, or personal data into this repository.

Selection criteria: final quality, performance, maintainability, maturity, security, license, ecosystem, integration, learning cost, portability, lock-in, longevity, scaling limits, and migration/rewrite risk.

After work, reusable technical lessons may be proposed back to this Shared layer only when they are generalized and stripped of private context.
