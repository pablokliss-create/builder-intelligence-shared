# ChatGPT Work Bootstrap

Before substantial technical work:
1. Sync or fetch the latest Shared repository and read `../AGENTS.md`, `../VERSION.json`, and `../CHANGELOG.md`.
2. Load only the registry/policy files relevant to the current task.
3. If an authorized private-memory overlay exists for the current user, load its bootstrap plus the relevant project memory separately from Shared.
4. Inspect the target project's real repository and project-local `AGENTS.md`, `CLAUDE.md`, `.builder-intelligence/`, tests, and current implementation before acting.
5. Resolve conflicts using: tested project reality > latest explicit user decision > authorized private memory > Shared generic intelligence > stale chat memory.
6. Revalidate volatile facts before high-impact technical decisions.
7. Write durable private lessons back to the private layer; only generalized/sanitized knowledge may be proposed to Shared.

Do not assume chat memory is canonical when shared/project sources exist. Never copy private project context, secrets, credentials, or personal data into Shared.
